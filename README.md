# Remittance-Reer-Uzbekistan

Ongoing research task that tackles Uzbekistan's cash flow from work abroad that answers four questions:

Do remittances and currency strength move together over the long run, not just by coincidence?
Did that relationship change after 2017, since the exchange rate only became "real" that year?
Does the currency react differently to a remittance surge than to a remittance drop?
If we compare Uzbekistan to neighbors with heavier remittance dependence — Tajikistan (~45% of GDP) and Kyrgyzstan (~24%) — does the effect get stronger as dependence increases? That's a dose-response check, like testing whether a bigger dose of a drug produces a bigger effect.
